# X快捷判胜与傀儡立绘（2026-09-09）

## X 快捷胜利

- 仅已启动、未结算的战斗场景响应 `X`；菜单和战斗结果页不会响应。
- 按键自动重复（key echo）会被忽略。终局后的再次按键也不会再次提交奖励或成长。
- 暂停时战斗场景处于禁用处理状态，因此 `X` 不可用；先继续战斗再使用。
- 快捷胜利不会伪造敌方死亡、不会修改双方生命。它通过 `BattleOutcome.force_win` 调用普通胜利相同的外部接受、状态提交、日志和 `battleResolved` 通知链路。
- 发出胜利前会取消尚未播放的卡牌/伤害表现并确认这些旧事件，随后只播放终局批次。Run 战斗仍在终局表现完成后经 `RoguelikeBattleAdapter.settle_if_terminal` 写入奖励、成长和棋子生命比例。

## 傀儡兵种立绘

- 新增纯代码全身木铜机关人：横控杆、悬丝、雕木头部、胸口菱形核心、外露关节和分离四肢。
- `is_puppet`优先选择独立绘制，避免召唤物继续显示普通甲卒。敌方镜像与赭红点缀、我方青玉点缀、动作姿态和死亡变暗沿用现有接口。
- GPT-6子agent完成绘制，主agent检查实际千机召唤后的战斗截图及敌我/死亡三态总览。没有改召唤位置、数值或技能规则。

- `tests/run_instant_victory.gd`：快捷键、正常Run结算和重复触发保护。
