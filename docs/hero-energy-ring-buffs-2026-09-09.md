# 弈者能量环与动态状态（2026-09-09）

## 已实现

- 双方弈者头像外围显示真实能量比例，顺时针增长。我方灰绿、敌方铜色；旧装饰环和单列能量条隐藏，避免混淆。悬停头像显示精确能量。
- 单人采用居中的头像、名字与状态组合；多人采用方形头像在左、名字与状态在右。能量环不另占一行。
- 状态以动态标签排列：名称、多层数值、悬停说明。不显示“拳势 0/5”或未生效的占位进度。
- 接入拳势、永久拳意、炎华成长、引火本场已用、殉道已启用。永久成长从真实成长快照读取；零层不显示。
- 统一状态数据为 `statuses`，界面不按弈者固定配置状态槽。多个标签自动换行，状态消失后移除。
- 能量绘制由 GPT-6 子 agent 完成，基础 UI 由 Luna 子 agent 执行，Terra 子 agent 验证，主 agent 收尾布局和集成检查。
