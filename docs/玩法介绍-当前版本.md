# 《弈者》玩法介绍（当前版本锚点）

> 本文记录当前可玩版本的规则锚点。产品决定可以改变本文；确认改动时，必须同时更新实现与测试，不能把本文当成不可变的历史设定。

## 状态标记

- **已实现**：当前 Run、BattleController 和 Godot UI 可以实际走通的规则。
- **已确认、待实现**：产品已确认，代码尚未接入。
- **候选提案**：尚未确认，不进入卡池、存档、平衡或 UI 承诺。
- **实现缺口**：目录或旧文案已有承诺，但当前入口未实现该效果；不得当作可用能力推导平衡。

当前不开放神通决策面板；`charge`、`assault`、`sacrifice` 及其两件进化遗物仍为休眠内容，不接入 Run 或战斗输入。

## 目标

单局目标是让四名弈子、弈者牌组和遗物穿过三章地图，并击败第三章 Boss。每场战斗的直接目标是消灭对方全部能维持战局的弈子；弈者负责把卡牌、能量和本场附魔转化为棋盘优势，弈子负责占位与攻击。弈者不再获得跨战斗永久属性成长。

## 已实现：Run 循环

1. 新局从 **3 名**非命轮弈者中选 1 名，不再强制提供永久成长型弈者。开局取得两种不同的零费自由技，各一张，额外取得两张“棋子行动”。
2. 每章地图为三行十列；玩家沿可达节点前进。节点包括普通战斗、精英、Boss、商店、锻造和事件。
3. 战斗胜利结算货币、奖励与弈子生命比例。战内拳势、将军属性与炎术附魔不带入下一场。第三章 Boss 胜利为 `cleared`，战斗失败为 `failed`。

新局初始货币为 **30**。普通战斗奖励 `15` 货币、必定卡牌三选一，并独立以 **30%** 概率掉落遗物三选一；卡牌与遗物各选一项、也可分别跳过，互不占用领取机会。30% 是本轮首版参数。精英仍为 `25` 货币和 `2` 张卡牌、`1` 个遗物的混合三选一；Boss 仍为 `40` 货币和 `1` 张卡牌、`2` 个遗物的混合三选一。卡牌候选混合自由技与当前上阵弈者解锁的专属牌；实际候选由节点、已持有内容和权威快照限制。

普通战同时掉落两组奖励时，先完整展示卡牌三选一；领取或跳过卡牌后，再进入独立的遗物三选一。页面刷新或恢复存档按尚未处理的奖励继续，不把两组挤在同一页。

### 四人阵型与库存

Run 保留六个位置，但新局只有四名弈子：

| 槽位 | 默认状态 |
|---:|---|
| 1 | 空 |
| 2 | 甲卒（唯一默认前排） |
| 3 | 空 |
| 4 | 死士 |
| 5 | 机弩 |
| 6 | 旗兵 |

- 空位是未占用位置，不是生命为 0 的阵亡棋子，不能被治疗或成长激活。
- 地图“调整阵容”允许四名既有弈子换位，或替换已占用位置的兵种；库存不能拖进空位新增第五、第六名弈子。
- 甲卒、死士、机弩、旗兵各有 **2** 份默认库存。历史六满存档可保留旧三甲卒，但换出后不能再超额加入。

## 已实现：战斗与卡牌

### 手牌、技能点与能量

- 战斗基础 SP 为 **4/4**，默认上限 **4**，每回合恢复 **2 SP**，常规回合恢复受上限限制。卡牌、遗物等回合内效果回复 SP 可以超过上限；结束玩家回合时仅清除超上限部分，上限内剩余 SP 保留。弈者积攒大招的能量是另一套资源，规则不变。
- 手牌上限 **7**；开场与每个非终局回合均按 `2 + N` 抽牌，`N` 为当前上阵弈者数。抽牌堆空时洗回弃牌堆。
- 弈者部署与弈子阵位是两套数据。当前弈者部署最多6个唯一槽位；四名初始弈子不意味着四名初始弈者，也不能按弈子数量计算抽牌。
- 牌库由自由技多重集、上阵弈者的主动专属技和运行中生成的大招构成。骑士专属为被动：不生成专属牌，但仍计入 `N`。
- 自由技成功释放后，全体上阵弈者获得 `5 + 实际消耗SP × 5` 能量；专属技成功释放后，所属弈者获得 `10 + 实际消耗SP × 10` 能量。免除费用时按实际0消耗计算，不能按卡面基础费用计算。
- 自由技与通常专属技成功使用后弃置；回气、筹策成功使用后本场消耗，不洗回抽牌堆。**影狩初始专属“潜影”成功结算后回到手牌，保留同一实例**，仍受 SP 与潜行目标条件限制。大招成功使用后消耗。回合结束时剩余手牌（含潜影）清理至弃牌堆，不保留整手到下一回合。
- 接受结束回合后，手牌区立即清空，剩余卡牌全部弃置（包括未用大招）；结算演出完成后显示新回合重新抽取的手牌。结束回合被拒绝时保留原手牌。
- 自由技、专属技、大招都是可拖拽的卡牌。斩杀拖到合法敌方单位指定攻击目标，我方攻击者仍自动取最高攻击弈子。棋子行动拖到我方存活弈子指定额外行动对象。封命首次拖到合法我方弈子指定将军；已有存活将军时重复施放只需拖出。其余既有牌仍自动选目标。千机后续专属点化可指定傀儡，未指定时自动选择。
- 指定目标时显示指向线、可选弈子描边与锁定准星，文字明确松手后作用的对象；拖出的卡牌淡出以减少遮挡。无效落点退回卡牌，不扣 SP。
- 能量达到弈者上限时，本次能量清零并生成一张该弈者大招；手牌已满则将大招置于抽牌堆顶。单次跨多个阈值只生成一次。
- 弈者能量以头像周围的环形进度显示，悬停头像查看当前值与上限；不再单列能量条。环形进度跟随真实能量，生成大招后随能量清零。
- 正在播放上一张牌时，仍可拖出其他可用牌进入结束回合按钮上方的等待队列。等待牌尚未向领域提交、不提前扣 SP；轮到它时重新校验。玩家指定目标随队列锁定，死亡或变得不可选时退牌且不扣费，不自动换目标；自动选目标的牌仍在结算时解析。等待项可取消；同一实例不能重复排队。
- 首次入队从实际释放位置平滑移入对应预览/牌签。队列未清空时不能结束回合，暂停与终局按各自规则冻结/清空。此展示规则不改变底层单卡顺序结算。

### 一回合的攻击段

当前开发版提供战斗快捷键 **X**：在进行中的、未暂停战斗里直接判胜，沿用正常胜利结算与 Run 奖励写回。不会伪造逐个击杀或修改双方生命；已经结束的战斗不能重复触发。此快捷键用于快速验证，不改变普通战斗胜负条件。

1. 玩家在 `player_input` 阶段打牌或结束回合。
2. 敌方弈者按敌方列表顺序，以既有敌方 AI、SP 与能量规则行动。
3. 棋子按槽位依次结算“我方棋子 → 敌方棋子”；额外行动、追击、反击和兵种效果在各自攻击链中触发。
4. 结算灼烧、临时状态衰减、回合资源恢复和下一回合抽牌；终局不再抽牌。

同一次攻击中的单段群攻同时展示各目标伤害；奥术导体触发的全体遗物伤害也作为一段同时播放，结算后高亮对应遗物并显示触发名称。宁不凡大招每一击为独立一段，逐段展示。反击与追击保持独立动作。暴击、格挡同时发生时只显示一个实际伤害数字，附“暴击·格挡”；完全格挡显示0。

目标选择、格挡、暴击、灼烧、傀儡及具体伤害数值以战斗目录与效果实现为准；旧版本数值长表不是当前权威来源。

### 弈者与战内成长

内容目录有 9 名玩家弈者；命轮不进入 Run 初始/招募候选，因此可选池为 **8 名**。主动专属会入牌库，每名弈者的大招由能量满时生成。

元帅、炎术士和宁不凡均不再产生跨战斗永久成长。旧存档 `permanent_buffs` 字段为结构兼容保留，但恢复时清空，正式战斗不投影旧属性。牌组、遗物、招募与阵容仍随 Run 保存。

| 可选弈者 | 专属技与核心职责 | 大招方向 |
|---|---|---|
| 赤焰 | 蔓炎扩大已有灼烧，基础消耗按场内次数1/2/4/8递增 | 利用目标灼烧层数造成群体单段伤害 |
| 元帅 | 2SP封命，首次指定弈子赋予将军附魔；重复自动作用存活将军，重复属性收益为旧版两倍，仅限本场 | 治疗将军并给予出征，出征仍属普通Buff |
| 骑士 | 被动反击，不产生专属卡 | 强化超级反击窗口 |
| 炎术士 | 初始专属赋予攻击附灼烧的火焰附魔；本场费用依次1/2/2/4，之后均4SP，不再每场限一次 | 炎汲续航 |
| 宁不凡 | 1SP拳劲，本场拳势无限叠加，不再产生永久拳意 | 逐段攻击，击杀追加段数并转火 |
| 沉戈 | 1SP破势，对敌方建立标记 | 全体破势与破阵领域 |
| 千机 | 1SP机巧造物，在可召唤位置生成傀儡 | 补充傀儡并启用殉道 |
| 影狩 | 1SP潜影，赋予非傀儡潜行并改变后续锁定 | 点杀与潜行单位追击 |

炎华按本场成功施放次数计费，同名专属卡副本共用次数。卡面同步显示当前费用，即使 SP 不足或暂时没有合法附魔对象也不回退到初始费用；施放失败不增加次数，新战斗重置。炎汲仪式大招不受此费用序列影响。

拳势每场从0开始、无上限；前5层沿用既有拳势效果，超过5层后每增加1层提供5%拳系增伤，不再追加旧永久拳意带来的大招段数。弈者自身计数显示在对应状态栏，弈子的附魔、破势等显示在弈子状态栏，阵营效果另列。

弈者状态按实际生效项动态排列为名称与层数标签，悬停查看说明。不显示零层拳势或未启用状态；消失的状态释放位置，多个状态自动换行。取消旧永久拳意、永久投资显示。

### 普通 Buff 与附魔

附魔仍由 Buff 系统管理，是受共存数量限制的一类 Buff。增伤、临时格挡、减伤、灼烧、出征等普通 Buff 不占附魔槽；将军身份及其成长、攻击附灼烧属于附魔。

棋子行动施加的额外行动也属于普通 Buff：每层在施放后的下一回合生效，当前回合攻击段不提前触发。同一弈子可同时持有本回合已就绪与下回合待生效的层数，界面分别显示；就绪层在行动后消耗，在生效回合未能行动也会到期清除。敌方旧式技能仍沿用原来的额外行动规则。

- 普通弈子同时最多两种附魔，第三种自动替换最早施加的一种；同种重施沿用其叠层规则，不额外占位、不刷新先后顺序。
- 将军附魔被替换时同步清除将军身份并撤回其累计属性，下次封命重新选目标。
- 傀儡默认不能附魔。千机后续专属 **点化**（1 SP）使一名尚无资格的存活傀儡获得一个附魔槽；资格只限本场。
- 火焰附魔使弈子攻击附带灼烧，灼烧本身属于普通负面 Buff。各类附魔只按自己定义的行动事件触发，不把占格数量当成触发次数。

### 已实现：弈者专属牌池扩展（2026-09-09）

- **初始专属**：选择、招募并上阵主动专属弈者后，战斗牌库获得该弈者初始专属一张。重复进入战斗不累计赠送；骑士被动仍不生成初始专属。
- **获取候选池**：当前上阵弈者解锁其初始主动专属和已定义的后续专属，参与战后/商店的卡牌候选；解锁不等于自动获得全部牌。大招仍只由能量生成，不进该候选池。
- **副本**：奖励、购买获得的额外专属副本独立持有，不混入自由技ID列表；每份在战斗中成为独立卡牌实例。重复副本不会增加上阵弈者数N。
- **归属**：后续专属以对应弈者为施法者，只给予该弈者专属技能量收益，不使用自由技的全体能量规则。
- **首张后续专属：沉戈·乘隙**，1SP。敌方存在存活破势单位时，我方攻击最高的存活非傀儡获得2层追击；攻击相同按槽位、单位ID稳定选择。立即增加追击层数，不立即发动攻击，也不强制追击命中破势目标。条件失效则不可出牌，不扣SP。

### 当前自由技池：定义与实际状态

目前12种自由技可进入玩家构筑，允许重复副本。Run新局从零费池取两种不同的牌（当前即小回血和灼痕标记），再额外加入两张“棋子行动”，共四张自由技。不使用角色目录中的旧初始自由技配置。棋子行动是初始卡，不再进入后续奖励、商店等获取候选池；已持有的卡正常使用，旧存档不补发。回气、筹策从奖励/商店获取，不改变初始牌组。

| 自由技 | 基础SP | 规则摘要与当前状态 |
|---|---:|---|
| 基础叠层 | 1 | 敌方全体各1层灼烧，每目标30%概率额外1层 |
| 灼烧引爆 | 2 | 引爆灼烧最多的可锁定敌人，每层5伤害并清层，击杀后分配原灼烧 |
| 斩杀 | 2 | 最高攻击我方弈子对拖拽指定的合法敌人造成150%直接伤害，击杀返1SP |
| 棋子行动 | 1 | 初始两张，后续获取池不再出现；指定我方存活弈子（含傀儡）获得下一回合额外行动1次，以普通Buff显示，可叠加，不占附魔槽 |
| 棋子格挡 | 1 | 全体我方弈子本回合临时格挡率+15%，接入正式格挡计算 |
| 棋子增伤 | 1 | 全体我方弈子本回合直接伤害+25%，文案与实际配置统一 |
| 棋子回血 | 1 | 全体存活我方棋子各回复5%最大生命 |
| 小回血 | 0 | 当前生命比例最低的存活我方棋子回复5%最大生命 |
| 灼痕标记 | 0 | 灼烧最多的可锁定敌人增加1层灼烧 |
| 血移 | 1 | 最高生命者得到易伤，其余得到庇护，正式承伤倍率生效 |
| 回气 | 1 | 回复2 SP，可在本回合超过上限；成功使用后本场消耗 |
| 筹策 | 1 | 抽2张牌；打出后须有两个手牌空位，抽牌堆与弃牌堆合计至少有2张牌；成功使用后本场消耗 |

设计新自由技仍须验证实际伤害/格挡与资源结果。旧扩充提案仅供历史参考，未在本表列出的牌不自动进入正式池。

### 敌方弈者按层数

Run 复用已有军令、铁卫、千机定义的专属技、技能池和能量上限：

| 章节 | 敌方弈者 |
|---:|---|
| 1 | 敌·军令（101） |
| 2 | 敌·军令（101）、敌·铁卫（102） |
| 3 | 敌·军令（101）、敌·铁卫（102）、敌·千机（103） |

普通、精英和 Boss 均按当前 Run chapter 生效。此规则只用于带 Run progress 的启动配置；M4 直开仍使用所选 stage 的原始完整敌方 roster。

### 敌方弈子与多格特殊怪物

每章普通战各有两种不同兵种编队，包含甲卒、死士、机弩、旗兵及空位，不再统一六个甲卒。精英和 Boss 使用特殊怪物配护卫/输出的编队。

- **噬元兽**：单实体占两格。每次攻击命中吞噬玩家最多1 SP，SP耗尽时转为吞噬一名上阵弈者最多10能量。吞噬的资源显示与该次命中同步，资源区提示实际损失量，并播放能量吸向噬元兽的简约特效。
- **回响**：单实体占三格。受到直接伤害后累计1%伤害加成，按既有规则排除延迟伤害。
- 多格实体只有一个单位ID、一条生命、一次正常行动。占用的其他格不生成第二个单位，不重复承受群体伤害；拖到任一占用格均选中同一实体。
- 占格沿同一列连续排列，代码立绘覆盖其实际占用区域；形状、名称和悬停说明区分两种怪物。

## 已实现：遗物、经济与保存

- 遗物目录有 22 个定义；两件神通进化遗物依赖休眠神通，已从实际 Run 候选过滤。因此当前可获得池为 **20 件**有效遗物，包含通用、兵种强化和精英来源内容。
- 商店提供自由技、已解锁专属牌与遗物候选；锻造提供兵种强化遗物并可治疗。价格、折扣和可出售自由技由章节、遗物持有状态和权威 option snapshot 判定，UI 不自行计算。本轮未开放额外专属副本出售。
- 自由技按允许重复的 ID 多重集保存；购买、奖励、出售都按一份副本处理。`basicDamage` 保留底层 handler，不进入玩家牌库、商店或奖励。
- Run 在创建、成功的安全状态变更和进入节点前保存 checkpoint。打开中的战斗进度对象不直接存档，节点启动前保存可恢复的地图状态。
- checkpoint 保存 Run 状态、随机源及奖励/商店 authority；恢复时验证结构、内容引用和历史兼容迁移。篡改的候选或 authority 会被拒绝。
