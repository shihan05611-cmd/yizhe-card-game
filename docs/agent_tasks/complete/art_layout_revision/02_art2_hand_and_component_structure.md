## 依赖

## 实现要求

1. 卡面调整为 150×210，内部区域同步重排；费用保持正圆，移除 InstanceId 调试字样，标签归入单一 tag 行。
2. 描述区按三行预算，超出省略；hover/tooltip 提供完整说明，并保留不可用原因。
3. 7 张总宽不超过 1000；间距不低于卡宽 0.72，空间不足时整体缩放。
4. 正常绘制顺序保持右牌覆盖左牌右缘，不反转为左压右；确保名称、费用、类别位于左侧安全区或顶部 56px。hover 1.08、上移 28、投影、置顶，且不改变邻牌布局。
5. 旋转外接框上下左右均纳入边界断言；0/1/7 张均可布局。
6. 棋子职业本地化；无 Buff 行隐藏；存活不显示状态字，阵亡用灰化与场景内斜线/裂纹标记，名称用节点装饰表达删除线；HP 数字叠在条上。
7. 标题删除 `2×3` 调试规格。
8. 结果/fatal 使用一致的居中卡片、描边、投影与主按钮版式，不改变其现有信号和可见状态逻辑。
9. 敌方占位和立绘条目保持同尺寸、圆角与描边；不补新图。
