- 使用独立 Review 角色，只读检查，不修改实现。
- 代码层只检查解析/运行风险、接口路径、分层边界、测试可运行性。

4. Tab/L/按钮同入口，未读角标、自动滚底和终局不强开可验证。
5. 动态可见对象仍由 `.tscn` / PackedScene 实例化；无新增即时绘制。
6. P2 项未提前实现；敌方缺图只保留一致占位。
7. ART 聚焦、M4 聚焦、图形 smoke、常规非稳定性回归可运行；未运行 1000 场。

## 输出

- PASS/FAIL。
- 按 P0/P1/P2 列发现；无发现也明确写 0。
