# ART-3 顶栏 HUD 与战斗日志抽屉

## 目标

实现 A2 与 B3：把日志改为默认隐藏的可召回抽屉，并将顶栏整理为左、中、右三组。

## 允许范围

- `project.godot` 的 `toggle_combat_log` InputMap
- BattleScreen、BattleHud、CombatLog 相关 `scenes/` 与 `ui/`
- 本批聚焦测试与视觉夹具

## 禁止范围

- 不修改 Controller、VM、事件合同、表现队列时钟或战斗输入锁语义。
- 不修改卡牌/手牌、棋子格或结果/fatal 内部组件。
- 不推进第二期 Theme、色板、字体、立绘、FX。

## 依赖

- ART-1 骨架完成并提供稳定 MainRow/日志插槽。

## 实现要求

1. 日志默认 `visible = false` 且不占 MainRow 宽度；Tab 与 L 映射 `toggle_combat_log`，由 `_unhandled_input` 与 HUD 按钮调用同一入口。
2. 抽屉打开宽 300，内容从右侧 0.18 秒 EASE_OUT 滑入/滑出；不调用队列忙锁，不阻断卡牌拖拽、倍速或自动战斗。
3. 关闭期间按新增日志数累计未读角标，上限 `99+`；打开立即清零。终局/fatal 保持当前开合状态。
4. 日志列表保持时间顺序并自动滚到底；抽屉高度跟随 MainRow。
5. HUD 左组为回合与 SP 条+数字，中组为抽/手/弃/耗四个短标签节点+数字，右组为倍速段、自动、日志、结束回合。
6. 删除重复的 SpeedLabel；倍速按钮自身高亮。结束回合使用唯一高对比主按钮，点击区不小于 120×44。
7. 日志按钮有按下态与未读数字，不能只靠颜色表达。

## 完成条件

- 聚焦测试覆盖 Tab/L/按钮同入口、默认退出布局、0.18 秒非阻塞、未读累计/清零、终局不强开、自动滚底、HUD 三组与按钮尺寸。
- M4 场景、表现与图形 smoke 回归通过；未运行 1000 场。
