# M5-03 Run 生命周期

## 目标

迁移开局、选人、地图前沿、节点选择、章节推进、招募、部署和结局状态，建立不依赖 UI 的完整 Run 流程。

## 允许范围

- `systems/roguelike/` 下新增或扩展 Run 领域服务。
- 对 `autoload/run_state.gd` 增加薄转发或生命周期持有能力。
- 新增 Run 生命周期、招募、部署和状态不变量测试。
- 使用 M1 英雄／技能目录和 M5-02 地图结果。

## 禁止范围

- 不实现奖励、商店、锻造的价格与购买细节。
- 不启动真实战斗，不提前实现战斗结算桥。
- 不制作地图或选人 UI。
- 不迁移 `equippedFreeSkillIds`、技能槽配置、槽位直放技能。
- Run 开始不选择神通，神通状态不参与活动 Run 不变量。

## 依赖

- M5-01 Run 契约与事务随机。
- M5-02 地图接口。
- M3 卡牌重制冻结规则。

## 完成条件

- Run 能从 idle 进入选人／地图，合法推进三章并进入 cleared 或 failed。
- 初始两张不同零神机免费技能各加入一张，所有权允许后续重复。
- 招募增加阵容人数并使主动英雄专属牌在后续战斗可被装配；骑士被动不生成牌。
- 节点只能从当前前沿选择，已完成节点不能重复结算。
- 放弃和失败能回到一致的非活动状态。
- 聚焦测试通过并回报证据。
