# M5-02 地图与遭遇生成

## 目标

迁移三章 `3×10` 肉鸽地图、节点可达关系、类型权重和遭遇缩放，使同种子结果与 Web 逐节点一致。

## 允许范围

- `systems/roguelike/` 下新增地图与遭遇生成代码。
- 读取并复用 M1 肉鸽内容目录。
- 新增地图金标、可达性、遭遇预算和边界测试。
- 必要时新增测试 fixture，但必须说明其 Web 来源和生成方式。

## 禁止范围

- 不实现 Run 节点状态机、经济、战斗启动和 UI。
- 不修改 M1 的权威目录值来迎合测试。
- 不引入 M6 遭遇变换器、批量采样或平衡结论。
- 不进行 1000 次稳定性回归。

## 依赖

- M5-01 的 Run/RNG 契约。
- M1 `roguelike_content_catalog.gd`。
- Web `map-system.js` 作为行为基准。

## 完成条件

- 每章准确生成 30 个稳定 ID 节点，首列、相邻行连边、Boss 和前沿规则正确。
- 三章固定种子逐节点类型及连边与 Web 金标一致。
- 战斗、精英、Boss 的 HP/攻击预算及槽位分配与 Web 一致。
- 非法章节、节点或遭遇输入按领域错误明确拒绝。
- 聚焦测试通过并回报证据。
