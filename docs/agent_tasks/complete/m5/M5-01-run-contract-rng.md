# M5-01 Run 契约与事务随机

## 目标

建立 M5 的纯内存 Run 权威状态、状态转换基础契约和与 Web 等价的事务随机适配器，为后续地图、经济和战斗结算提供稳定接口。

## 允许范围

- `systems/roguelike/` 下新增 Run 状态模型、共享校验与事务随机代码。
- 对 `autoload/run_state.gd` 做保持薄适配器定位的必要修改。
- 新增 M5 契约和事务随机的聚焦测试及测试入口。
- 只在确有必要时对 `core/rng.gd` 增加窄接口；优先通过 M5 适配器实现 Web 的重放式事务语义。

## 禁止范围

- 不实现地图、奖励、商店、锻造、战斗桥接或 UI。
- 不实现存档、读取、版本迁移、`user://` 写入。
- 不把神通字段设为活动 Run 的必填项，不接入神通使用次数。
- 不修改 M2 战斗规则、M3 牌堆和 M4 场景。

## 依赖

- M0 `Rng` 的命名流与确定性约定。
- M1 内容目录只作为后续契约背景，本批不得提前消费玩法内容。
- 已确认的 M5 范围与 `docs/migration-plan.md`。

## 完成条件

- 新建、重置、快照 Run 状态的接口明确，状态数据不包含 Web 旧版装备技能槽权威逻辑。
- 免费技能所有权预留为允许重复的 ID 数组／多重集。
- 同种子事务提交会保留随机推进；返回 `false` 或抛错会回滚到等价抽取序列。
- 拒绝嵌套事务和异步结果，与 Web 边界一致。
- 聚焦测试通过，并提供命令、通过数量和关键断言证据。
- 工作区无本批范围外改动。
