# M5-05 战斗桥接与进度提交

建议：`gpt-5.6-terra` / `high`

Allowlist：`systems/roguelike/`、`app/`、M4 冻结入口相关的 `autoload/` 与战斗装配窄接口、M5 相关 `tests/` 与阶段证据文档。

## 目标

把 Run 的阵容、免费技能牌多重集、普通遗物、永久成长和遭遇配置注入现有战斗层，并迁移胜利提交、失败回滚和跨战斗生命值逻辑。

## 允许范围

- `systems/roguelike/` 下新增战斗进度会话。
- `app/` 下新增肉鸽战斗适配器／控制器。
- 对 `battle_bootstrap.gd`、`battle_controller.gd`、`game_root.gd`、`signals.gd` 做保持 M4 直开战斗兼容的窄幅修改。
- 新增战斗桥接、牌库注入、生命值和永久成长提交测试。

## 禁止范围

- 不修改 M2/M3 的权威战斗、手牌、牌堆规则来迁就 Run。
- 不允许 Run UI 或 Run 状态直接修改战斗牌堆。
- 不把 Web `freeSlots` 或英雄 acted 标志重新引入卡牌回合。
- 不接入神通或两件神通进化遗物。
- 不实现正式肉鸽 UI。

## 依赖

- M5-03 Run 生命周期。
- M5-04 奖励与所有权状态。
- M2 永久成长草稿、遗物运行时。
- M3 `BattleCardSession` 配置契约。
- M4 战斗入口和结果读取契约。

## 完成条件

- 每次战斗从 Run 显式构建部署英雄和免费技能 ID 多重集；重复副本不被去重。
- 主动英雄专属牌和骑士被动规则沿用 M3，不在 M5 复制实现。
- 胜利提交最终生命比例和永久成长，失败丢弃本场进度。
- 奖励治疗不复活，锻造恢复可复活并补满全部槽位。
- 普通遗物进入战斗；两件神通进化遗物即使存在于目录也不进入实际 Run 战斗。
- M4 直开战斗路径保持可运行。
- 聚焦测试通过并回报证据。
