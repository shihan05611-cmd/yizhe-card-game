# M5-04 经济与非战斗节点

建议：`gpt-5.6-terra` / `medium`

Allowlist：`systems/roguelike/`、M5 相关 `tests/` 与 fixture／测试入口、M5 阶段证据文档；Web 参考工程仅只读。

## 目标

迁移战斗奖励、商店、锻造、事件、货币、价格、选项权威快照和原子结算，并适配免费技能牌允许重复的新规则。

## 允许范围

- `systems/roguelike/` 下新增或扩展奖励及经济领域代码。
- 普通遗物和职业升级遗物按 Web 规则进入相应池。
- 新增经济、选项防篡改、回滚和重复技能测试。
- 必要时补充 M5 测试目录／fixture。

## 禁止范围

- 不启动或结算实际战斗。
- 不制作商店、锻造、事件 UI。
- 不接入神通。
- `shentongAssaultBurst` 与 `shentongChargeOverload` 不得出现在奖励池、商店池或完整 Run 流程。
- 不实现存档和跨进程恢复。

## 依赖

- M5-01 事务随机。
- M5-03 Run 生命周期和所有权契约。
- M1 遗物、免费技能与肉鸽内容目录。

## 完成条件

- 战斗／精英／Boss 奖励数量和货币、商店及锻造价格与 Web 默认规则一致。
- 免费技能奖励和商店允许获得已有技能的额外副本。
- `tradePermit` 出售技能时只移除一张副本。
- 锻造免费首次恢复、后续递增价格、奖励治疗不复活等规则正确。
- 选项采用权威快照，伪造、陈旧和重复提交均不改变状态或随机序列。
- 两件神通进化遗物被显式过滤并有测试锁定。
- 聚焦测试通过并回报证据。
