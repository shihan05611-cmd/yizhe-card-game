# 自由技扩充提案·第一批

状态：**候选设计，尚未实现、未进入卡池。** 日期：2026-09-09。下列费用、数值与出现方式均为首轮测试起点，不是已经确认的规则。

2026-09-09后续决定：**乘隙已从自由技候选移出，改为沉戈的后续专属牌**，按沉戈上阵解锁候选。下文保留原设计供追溯，其自由技分类与原投放建议不再适用；其余7张仍是候选。

当前规则见 [玩法锚点](玩法介绍-当前版本.md)。本提案扩充可选择的战术工具，不增加新局自动获得的牌数，也不直接给弈者增加永久成长。

## 设计判断

当前玩家自由技有10种：基础叠层、灼烧引爆、斩杀、棋子行动、棋子格挡、棋子增伤、棋子回血、小回血、灼痕标记、血移。灼烧已有铺层、集中、引爆三个环节；治疗和普攻增益也已有基础选择。比较缺的是解负面状态、保护濒死单位、针对高攻击敌人的防御，以及空位/傀儡和非灼烧流派的配合。

不再新增一批伤害更高的斩杀或效果更大的群疗。自由技要补弈者的短板，不能替代千机造傀儡、元帅培养将军、炎术士永久附魔或宁不凡积累拳意。

我建议设计8张，先实现前6张做小池测试，后2张在资源循环验证后加入。初始仍只有小回血、灼痕标记各一张；新增牌从战后奖励与商店获得，不能一次性塞进玩家牌组。正式扩大池子前先比较候选出现率，避免关键专属技被大量自由技稀释。

本轮核对已发现：现有棋子增伤、临时格挡、血移庇护/易伤、困扰的状态与实际伤害回调尚未接通，详见玩法锚点“实现缺口”。因此护持、挫锋不是简单换名即可上线，必须先补对应基础计算并验证；目前不能用这些未生效旧牌的表现作为新牌强度基准。

### 具体结算约定

- **统一目标**：自动选择，不新增拖到指定人物的输入方式。目标在真正轮到该牌结算时选择；排队时的预览不锁死目标。排队后条件失效则沿用现有退牌行为，不扣SP。
- **平局**：生命比例、灼烧层数、攻击等主排序相同，依次按槽位、单位ID稳定选择。敌方单体选择遵守现有潜行/可锁定规则。空位与阵亡单位不能作为受益者。
- **净息**：有缴械者优先；随后比较灼烧层数，再比较是否困扰，最后按稳定平局规则。必须至少能移除一项指定状态才可用，不移除破势、血移易伤或永久成长。傀儡若带有这些负面状态也可被选中。
- **护持、挫锋**：同名效果不叠加强度，重复使用只刷新持续时间；持续到本回合对应衰减阶段。两者可以分别影响受击者与攻击者，按乘法结算，不能相加至100%免伤。它们属于拟定的新规则；若复用既有庇护/困扰状态，必须先核实并统一原有状态的伤害接线与数值，不能只复用名字就算完成。
- **乘隙**：追击沿用现有每次消耗1层的规则，不把“2层”解释成一次行动立即连打两次。优势是可跨行动保留，代价是需要破势条件且每次追击只有既有50%攻击倍率。先与1费“棋子行动”比较实际收益，再决定是否保留2层。
- **鼓舞**：额外20能量与自由技固有能量收益分别结算。目标在该牌效果开始时、固有能量奖励之前选定。按当前规则，正常支付1SP还会让全体上阵弈者各获得10能量；目标合计获得30，其余各10。实际0费时固有收益为5，不能仍按1费计算。到达大招阈值沿用归零/生成大招牌规则。
- **借位**：空位只指未部署的位置，不把阵亡弟子重复算成空位；活傀儡每名算一份，两者合计上限2。每份分给不同的存活非傀儡，不能对同一棋子重复发放；缺少足够受益者时只发实际能分配的份数。

## 第二组：先保留的两张

| 名称 / 暂定 ID | SP | 拟定卡面规则 | 暂缓原因与限制 |
|---|---:|---|---|
| 理牌 / `reorderHand` | 1 | 抽2张牌。本牌消耗。 | 解决当前回合牌型不合适的问题；需要新增单张自由技消耗语义与抽牌效果接线。无返SP、无复制、无从消耗堆回收。 |
| 截脉 / `cutMomentum` | 2 | 当前能量最高的敌方弈者失去20能量。 | 提供针对下一次大招的防御选择；必须验证敌方实际能量节奏，不能做成每回合廉价永久封锁。 |

理牌结算时先按成功出牌移出手牌，再抽牌；最多抽到7张，空间不足的牌留在抽牌堆，不额外丢弃。不能让理牌抽到自己。其消耗只限本场战斗，下场仍从持有牌库重新构建。与真名解放、零耗火花、重复副本共同测试，不能产生无限循环。

截脉只在至少有一名敌方弈者能量大于0时可用，目标失去的能量不超过当前值，不返还给玩家，不移除已经释放的大招，不使普通技能失效。平局按敌方队列顺序。20点是暂定值，重点观察它是否让第二、三层的敌方大招长期无法出现。

## 投放与验收

1. 第一轮先做6张候选，使用测试牌组验证；确认强度后再进入正式战后/商店候选。全部为非零基础费用，避免自动改变当前零费初始池。
2. 用单弈者、三弈者和可部署上限内的队伍分别测；弟子人数不等于弈者人数，抽牌仍按上阵弈者数`N`计算。
3. 与现有牌比较“这张牌什么时候更值得打”：护持对比格挡/群疗，乘隙与借位对比棋子行动，鼓舞对比花同样SP打专属技。若新牌在多数场景都更好，先削数值或加条件，不直接扩大旧牌数值追赶。
4. 必测组合：真名解放、零耗火花、奥术导体、旗兵、额外行动、追击、空位与傀儡、死亡导致条件失效、手牌7张、大招满能量即时生成、连续排队、1×/4×同结算。
5. 新效果必须有中文状态、来源、层数/持续时间与悬停说明。即时能量增减显示在弈者自身区域；没有新粒子美术也不能缺信息。
6. 只有通过验证并作出采用决定的牌，才移入玩法锚点“已实现”的卡池表。未采用的方案留在本提案，不让设计草稿覆盖当前规则。
