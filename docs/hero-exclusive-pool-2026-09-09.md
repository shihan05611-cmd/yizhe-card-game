# 专属牌池与影狩返手

## 产品决定

影狩初始专属潜影成功使用后回手。弈者上阵时，除了默认的一张初始主动专属，还解锁该弈者专属的获取候选池；候选可以包含初始专属的额外副本及后续主题专属。

沉戈的首张后续专属为乘隙：1SP，敌方存在存活破势单位时，己方攻击最高的存活非傀儡获得2层追击。它从自由技设计中移出，使用专属牌的所属弈者能量规则。

## 实现范围

- 手牌原有规则已让潜影保持同一实例回手，本轮补全结算区返手展示及卡面说明；不复制牌，不免除原有SP或潜行条件。
- 新增扩展专属目录，初始主动专属与后续专属分开定义，避免后续卡被自动当成第二张初始赠牌。
- Run以`exclusive_card_ids`保存额外专属副本；战斗组牌在默认初始专属之外加入这些副本。只为当前上阵主人组牌，副本不增加抽牌公式中的N。
- 卡牌奖励与商店的现有卡牌候选位混合抽取自由技和已解锁专属；不额外增加奖励数量，不投放大招或骑士被动。
- 专属候选展示名称、主人、费用、描述；额外专属持有情况可在Run查看。
- 旧存档迁移为空的额外专属持有列表，避免凭空增发；新版本存档仍严格验证字段与候选权威数据。

本轮没有将其余7张自由技候选加入卡池，也没有改动此前记录的增伤、格挡、血移与困扰计算缺口。

当前规则统一维护于[玩法锚点](玩法介绍-当前版本.md)。

## 验证结果

- 常规回归419项：418项通过，剩余1项是新增测试错误假设“商店后紧邻战斗”，实际还会经过招募奖励；修正测试路线后，相关专属获取套件3项、82条断言全部通过。最终生产代码未因该测试修订而改变，日志无脚本解析错误。
- 乘隙真实Controller出牌测试14条断言通过：失败不扣SP、成功只给沉戈能量、按最高攻击及槽位选择、两层追击、没有即时伤害。
- 返手展示测试12项、115条断言通过；额外飞行脚本32条断言通过，覆盖非零手牌旋转、落点位置/缩放/角度、暂停和清理。
- 新牌面1200×700截图已检查；补充短描述，避免“获得2层追击”被截断。复用现有牌面图形，没有新增绘制资产。
- Windows包已更新，启动检查退出码0，无脚本错误。构建环境仍有本机证书/编辑器设置保存提示。
