# 弈者状态与玩法锚点改动记录

日期：2026-09-09。

## 本轮改动

- 弈者卡片增加自身状态区：宁不凡战内拳势（含0层、上限5）、Run永久拳意、炎术士永久投资次数及本场已用状态、千机已启用殉道。
- 状态从战斗状态及真实GrowthPort快照读取；不向领域状态写入显示字段。敌方拳系弈者也可显示自己的拳势，不继承我方永久成长。
- 单弈者布局为状态预留底部空间；多弈者布局优先保留层数信息，悬停可读详细说明。
- 重写[玩法锚点](玩法介绍-当前版本.md)，在AGENTS.md中建立同步规则，区分已实现、待实现、候选和实现缺口。
- 提交[第一批自由技扩充设计](自由技扩充提案-第一批.md)：6张优先候选、2张资源类备选。没有修改正式卡池、开始牌组、SP费用或伤害计算。

## 本轮核对发现

现有增伤、临时格挡、血移与困扰状态的计算接线存在缺口，已逐项写入玩法锚点。旧棋子增伤文案为30%，配置为25%，正式伤害回调尚未应用；不能仅统一文案就称为修复。本轮没有改变这部分战斗数学。
